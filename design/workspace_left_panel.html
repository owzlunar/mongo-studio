วิธีแก้ปัญหาเรื่องปุ่ม "+connection" และ "+folder" ไม่ให้สับสนลำดับการกด

ข้อสังเกตของผู้ใช้ตรงจุดที่สุดครับ: ถ้ามีปุ่ม + Connection และ + Folder อยู่คู่กันด้านบน ผู้ใช้จะไม่แน่ใจว่าต้องกดอะไรก่อน-หลัง และถ้ายังไม่มีโฟลเดอร์แล้วกด + Connection จะเอาไปไว้ที่ไหน?

1️⃣ Smart '+' Context Menu

ที่แถบ WORKSPACES มีปุ่ม + เพียงปุ่มเดียว เมื่อกดจะมีเมนูให้เลือกชัดเจน:
1. New Connection...
2. New Project / Folder...
3. New Workspace...

2️⃣ In-line Hover '+' on Nodes

เมื่อเอาเมาส์ชี้ที่ Customer A จะมีปุ่ม + ปรากฏขึ้นสำหรับสร้าง Folder ในลูกค้ารายนี้ทันที และเมื่อชี้ที่ ERP จะมีปุ่ม + สำหรับสร้าง Connection ใน ERP ทันที รู้ context โดยอัตโนมัติ!

3️⃣ ไม่บังคับลำดับ (Non-blocking)

ในหน้าต่างเพิ่ม Connection ช่อง Workspace และ Folder จะเป็นแบบ Optional ถ้าผู้ใช้รีบๆ สามารถกรอก URI แล้วกดบันทึกเป็น Standalone ก่อนได้เสมอ แล้วค่อยลาก Drag-and-drop เข้าโฟลเดอร์ทีหลังได้

ปุ่ม Config & Import/Export (รักษาไว้ใช้งานต่อยอดได้เต็มที่)

  • ปุ่ม Config ที่ Header ด้านบน: สำหรับเปิด Quick Actions เช่น นำเข้า Connection จาก MongoDB Compass/URI, Export Workspace เป็นไฟล์ JSON เพื่อแชร์กับเพื่อนร่วมทีม (โดยสามารถเลือกซ่อนรหัสผ่านได้)
