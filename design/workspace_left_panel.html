1. Multi-Client & Multi-Project Workspaces

แยก Context ชัดเจนระหว่าง Client (เช่น FinTech vs Retail), Project Group (Folder เช่น Payments, Auth, Analytics) และ Environment (Prod, Staging, Dev, Local) ไม่ให้ปะปนกัน

  • Workspace Level: Top-level switch สำหรับแยกตามองค์กร/ลูกค้า มี config แยกหรือรวมใน workspace profile
  • Folder Level: Collapsible folder จัดกลุ่มตาม microservice หรือ project ย้าย/drag-and-drop ได้
  • Unified Mode: มีตัวเลือก "All Workspaces" สำหรับคนที่ต้องการดูภาพรวมทั้งหมดในหน้าต่างเดียว
🛡️

2. Environment Tagging & Production Safeguards

แก้ปัญหาการทำงานผิด environment โดยเฉพาะ Production ซึ่งสร้างความเสียหายร้ายแรงได้หากรัน Drop/Update ผิดตัว

🔴 PROD: Red Hazard border, Safe write mode, drop confirmation.
🟡 STAGING: Amber badge, mirror of prod testing.
🟢 DEV: Green badge, rapid prototyping & seed scripts.
⚪ LOCAL: Docker/localhost dev instances.
🦀

Proposed Rust Data Model Architecture

Backward Compatible

โครงสร้างข้อมูลใหม่ขยายจาก ConnectionConfig เดิม โดยเพิ่ม EnvironmentType และสร้างโมเดล WorkspaceConfig + FolderGroup: 

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, Default)]
pub enum EnvironmentType {
    Production,
    Staging,
    Development,
    #[default]
    Local,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FolderGroup {
    pub id: Uuid,
    pub name: String,
    pub icon: Option<String>,       // e.g. "💳", "👤", "📊"
    pub expanded: bool,
    pub connection_ids: Vec<Uuid>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct WorkspaceConfig {
    pub id: Uuid,
    pub name: String,
    pub icon: String,               // e.g. "🏢", "🛍️", "🚀"
    pub folders: Vec<FolderGroup>,
    pub ungrouped_ids: Vec<Uuid>,   // connections not in any folder
}

// In ConnectionConfig (Extended):
#[serde(default)]
pub environment: EnvironmentType,
#[serde(default)]
pub safe_mode: bool,               // Prompt before Drop/Delete
#[serde(default)]
pub tags: Vec<String>,             // Custom search tags
